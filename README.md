# Memory Game

Memory Game — игра на поиск пар одинаковых карточек.

Игрок открывает по две карточки за ход и старается найти все 8 пар за минимальное количество ходов.

## Возможности

- 16 карточек — 8 пар изображений
- случайное перемешивание карточек
- подсчёт количества ходов
- подсчёт найденных пар
- запуск новой игры без перезагрузки страницы
- модальное окно после победы
- таблица 10 лучших результатов
- сохранение результатов в localStorage
- адаптивный интерфейс

## Использованные технологии

- HTML
- CSS
- JavaScript
- DOM API
- LocalStorage
